# PEA Smart Vehicle (ระบบตรวจสภาพและบริหารยานพาหนะอัจฉริยะ PEA)

### แอปพลิเคชันระบบตรวจสภาพและบริหารยานพาหนะอัจฉริยะ การไฟฟ้าส่วนภูมิภาค (กฟภ.)
**Build Version:** `v0.6.6` (Cache Busting) • **Safety First Standard**

---

## 📌 1. ปัญหาที่พบก่อนมีแอปพลิเคชันนี้ (Pain Points)

1. **ความล่าช้าในการแจ้งซ่อม:** เมื่อพนักงานขับรถพบจุดที่รถชำรุด กว่าจะแจ้งเรื่องไปถึงช่างซ่อมและหัวหน้างานต้องใช้เวลานาน ทำให้รถที่มีปัญหาอาจถูกนำไปใช้งานและเกิดอันตรายได้
2. **กระบวนการที่ใช้กระดาษ (Paper-based):** การจดบันทึกการตรวจสภาพรถประจำวันหรือบันทึกการใช้งานรถด้วยกระดาษ ทำให้ข้อมูลสูญหาย ตรวจสอบประวัติย้อนหลังได้ยาก และไม่มีหลักฐานรูปภาพประกอบที่ชัดเจน
3. **ขาดการบริหารฟลีท (Fleet Management) แบบ Real-time:** หัวหน้างานไม่ทราบสถานะปัจจุบันของรถแต่ละคัน (เช่น คันไหนพร้อมใช้งาน คันไหนกำลังซ่อม คันไหนออกปฏิบัติการ) ทำให้ไม่สามารถจัดสรรทรัพยากรรถได้อย่างมีประสิทธิภาพ
4. **การซ่อมบำรุงเชิงป้องกัน (Preventive Maintenance) ไม่มีประสิทธิภาพ:** ขาดระบบแจ้งเตือนเมื่อรถวิ่งถึงระยะทางที่ต้องบำรุงรักษา (เช่น ทุกๆ 10,000 กม. ต้องถ่ายน้ำมันเครื่อง) ทำให้รถเสื่อมสภาพเร็วกว่าที่ควรจะเป็น
5. **ความล่าช้าในการต่อภาษี:** ขาดระบบแจ้งเตือนในการต่อภาษี ทำให้มีผลทางกฎหมาย

## 🎯 2. วัตถุประสงค์ (Objectives)

1. **ยกระดับสู่ระบบดิจิทัล (Digital Transformation):** เปลี่ยนการตรวจสภาพรถและการเก็บข้อมูลทั้งหมดให้อยู่ในรูปแบบ Paperless และสามารถเข้าถึงข้อมูลผ่านมือถือ/คอมพิวเตอร์ได้ตลอดเวลา
2. **เพิ่มความปลอดภัยสูงสุด (Safety First):** มีระบบแจ้งเตือนอัตโนมัติหากพบรถที่ "ชำรุด" หรือ "ถึงระยะซ่อมบำรุง" โดยจะถูกระงับการใช้งานจนกว่าจะซ่อมและผ่านการอนุมัติ
3. **เพิ่มความโปร่งใสและตรวจสอบได้:** มีการเก็บ Log ประวัติการทำงานทุกขั้นตอน พร้อมการแนบรูปถ่ายทั้งก่อนและหลังซ่อม ทำให้หัวหน้างานสามารถตรวจสอบความถูกต้องได้เสมอ
4. **การจัดการฟลีทรถที่มีประสิทธิภาพ:** ให้หัวหน้างานมี Dashboard แบบ Real-time สำหรับบริหารงานรถ สรุปสถิติ แจ้งเตือนสถานะต่างๆ และสามารถอนุมัติการซ่อมผ่านแอปได้ทันที

## 🚀 3. สิ่งที่เสริมและพัฒนาเพิ่มเติม (New Features & Enhancements v0.6.6)

1. **ระบบบิวด์และป้องกันแคชเก่า (Cache Busting v0.6.6):**
   - ปรับใช้การอัปเดตรุ่นของไฟล์บิวด์ `v=0.6.6` ในการเรียกใช้ไฟล์ CSS และ JavaScript ทุกลิงก์ ช่วยเคลียร์และป้องกันเบราว์เซอร์โหลดไฟล์สไตล์ชีตหรือสคริปต์รุ่นเก่าค้างในเครื่อง
2. **การรวมผลประวัติกิจกรรมซ่อม (Log Consolidation):**
   - ปรับปรุงระบบบันทึกงานซ่อมที่มีหลายจุดชำรุดในใบแจ้งซ่อมใบเดียวกัน ให้รวมประวัติเป็น 1 รายการแถวเดียวในตารางกิจกรรมแทนการขึ้นซ้ำแยก ช่วยประหยัดพื้นที่ฐานข้อมูลและทำให้อ่านง่ายกระชับ
3. **ชุดสีส้มความปลอดภัย legibility (Safety Orange Theme Overrides):**
   - ปรับปุ่มรองและ Outline ทั้งหมด (เช่น ปุ่มดูรายงาน, เพิ่มรถเข้าฟลีต, ค้นหาทะเบียน, บันทึกซ่อม) เป็น **สีส้มสดเข้ม (`#ff6600` / `#ea580c`)** พร้อมตัวหนังสือและไอคอนข้างในเป็น **สีดำสนิท (`#000000`)** เพื่อให้อ่านง่ายไม่กลมกลืนกับพื้นหลังสีม่วง PEA หรือสีขาว
   - ปรับปรุงความคมชัดระดับเลเบล (Placeholder) ให้มีสีเข้มขึ้น อ่านและค้นหาได้ชัดเจนทุกสภาวะการทำงาน
4. **การตอบสนองหน้าจอขั้นสูง (Responsive Header):**
   - ใช้ CSS Media Query `@media (max-width: 1150px)` ให้ปุ่มบนส่วนหัวหน้าจอซ่อนป้ายข้อความอัตโนมัติ เหลือเพียงไอคอนเมื่อหน้าจอถูกย่อจนต่ำกว่า 1150px เพื่อป้องกันปัญหาปุ่มล้นขอบหรือบดบังเมนู
5. **โหมดกลางแดดความคมชัดสูง (Sunlight Mode):**
   - สามารถสลับระหว่างโหมดห้องควบคุม (Dark Mode) และโหมดกลางแดด (High Contrast Light Mode) เพื่อให้พนักงานตรวจสภาพรถกลางแจ้งอ่านหน้าจอได้อย่างชัดเจน

## ⚙️ 4. หลักการทำงานของระบบ (Work Principles)

1. **ระบบสลับโหมดออนไลน์/ออฟไลน์อัจฉริยะ (Smart Offline/Online Fallback & D1 Sync):**
   - ตัวหน้าบ้านตรวจเช็คสถานะเครือข่ายตลอดเวลา หากออฟไลน์จะบันทึกและสลับมาจำลองกระบวนการทำงานผ่าน `localStorage` พร้อมจัดเก็บคำสั่งสร้าง/อัปเดตไว้ในคิวจำลอง (`pea_offline_sync_queue`)
   - ระบบพร้อมซิงค์ข้อมูลกับ RESTful APIs ขึ้นคลาวด์ Cloudflare D1 (SQLite) ทันทีเมื่อกลับมาออนไลน์
   - มีปุ่มสลับโหมดเน็ต (Auto / Offline / Online) ให้ทดสอบการทำงานได้อย่างอิสระ
2. **ความเสถียรและความโปร่งใส (Audit Logs & Push Alerts):**
   - ทุกประวัติการตรวจสภาพ (Inspection) หรือการปิดใบงานซ่อมบำรุงจะบันทึก Audit Logs อย่างละเอียด
   - ส่งสัญญาณ Push Notification และเสียงเตือน (Web Audio API) ไปยังบราวเซอร์ของผู้ปฏิบัติงานในกลุ่มบทบาทงานนั้นๆ (Driver, Mechanic, Supervisor) ทันที

## 👥 5. ระบบรองรับ 3 บทบาทการทำงาน (Roles)

1. **พนักงานขับรถ / ผู้ตรวจสภาพ (Driver / Inspector):**
   - ค้นหาและเลือกรถยนต์ (จดจำรถที่ตรวจล่าสุดอัตโนมัติ)
   - บันทึกเลขไมล์, ระดับน้ำมันเชื้อเพลิงคงเหลือ และปริมาณการเติมเชื้อเพลิง พร้อมตรวจสอบรอบ PM 10,000 กม. / วันต่อภาษี
   - แบบฟอร์มตรวจประเมินสภาพ 4 หมวดหมู่ (ภายนอก, ภายใน & ห้องเครื่อง, เซฟตี้ PEA, เครื่องมือเฉพาะทาง)
   - บันทึกจุดชำรุดเสียหายพร้อมเปิดกล้องถ่ายภาพจริง หรือเลือกภาพตัวอย่างพรีเซ็ต
   - ประเมินผลความปลอดภัยทันที: พร้อมใช้งาน (READY), เฝ้าระวัง (WARNING), งดใช้งาน (CRITICAL - สั่งห้ามขับทันที)
2. **ช่างซ่อมบำรุงรักษา (Mechanic):**
   - ตารางรับงานแจ้งซ่อม (Active Repair Tickets) กรองตามความเร่งด่วน
   - ตรวจดูรูปถ่ายความเสียหายที่คนขับแนบมา
   - รับงานซ่อม และอัปโหลดภาพถ่ายหลักฐานหลังการแก้ไข (After Photo)
   - กดส่งมอบงานซ่อม (Mark as Repaired) ส่งต่อไปยังหัวหน้างาน
3. **หัวหน้าแผนกยานพาหนะ (Supervisor / Chief):**
   - แดชบอร์ดสถิติฟลีทแบบ Interactive (จำนวนรถทั้งหมด, พร้อมใช้งาน, เฝ้าระวัง, งดใช้งาน, ครบรอบ PM, ภาษีใกล้หมด)
   - กล่องคิวอนุมัติผลงานซ่อม: ตรวจสอบภาพเปรียบเทียบ ก่อน-หลัง ซ่อมอย่างสมมาตร แล้วกดอนุมัติ (Approve) เพื่อปลดล็อครถกลับเป็น Ready หรือ ตีกลับงาน (Reject)
   - ออกใบตรวจสภาพรถอย่างเป็นทางการ (Print / PDF) ขนาด A4
   - เพิ่มรถใหม่เข้าสู่ฟลีต กฟภ.

## 💻 7. วิธีการเปิดใช้งาน (How to Run)

แอปพลิเคชันเป็น **Standalone Responsive Web Application** สามารถเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งซอฟต์แวร์เพิ่มเติม:

1. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บบราวเซอร์ใดก็ได้ (Google Chrome, Microsoft Edge, Safari, Firefox)
2. หรือใช้ Local Server เช่น:
   ```bash
   # หากมี Node.js
   npx serve .
   # หรือ Python
   python -m http.server 8080
   ```
3. สามารถใช้งานได้อย่างสมบูรณ์ทั้งบนคอมพิวเตอร์ เดสก์ท็อป แท็บเล็ต และสมาร์ทโฟน
